# Proyecto-siete-Griselda-Martinez
Es una Aplicacion web para explorar los datos de anuncios de ventas de vehículos, en esta aplicacion los usuarios pueden interpretar informacion mediante gráficos (histograma y gráfico de dispersión). 
En el histograma podran identificar la distribución de precios, y en el gráfico de dispersión se reflejara la relación entre año del modelo y precio, diferenciando por tipo de combustible.

#Aplicacion
https://proyecto-siete-griselda-martinez.onrender.com

"app.py" contiene la aplicación de Streamlit
 "notebooks/EDA.ipynb" contiene el análisis exploratorio
 "vehicles_us.csv" es el dataset

Los pasos para correr la app localmente:
1- Activar el entorno virtual
2- Instalar dependencias con pip install -r requirements.txt.
3-Ejecutar streamlit run app.py
